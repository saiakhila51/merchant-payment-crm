# Smart Merchant Payment CRM

A Salesforce-based fintech CRM platform inspired by payment gateways like Cashfree Payments.

## Features
- Merchant onboarding and management
- Payment request creation and tracking
- Transaction lifecycle management (Pending → Paid → Failed → Refunded)
- REST API payment gateway simulation
- Automated reminders and fraud-risk detection
- Analytics dashboard

## Tech Stack
- Salesforce Apex
- Lightning Web Components (LWC)
- SOQL
- REST API Integration
- Salesforce Flows
- GitHub + Salesforce CLI
